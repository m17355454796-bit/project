# pthread_cond

这个目录用于练习 Linux `pthread` 条件变量，以及生产者消费者模型到简单线程池雏形的演进。

## 功能

- 使用互斥锁保护共享任务队列。
- 使用 `not_empty` 和 `not_full` 条件变量协调生产者/消费者。
- 使用 `Task` 结构体封装函数指针和参数。
- 使用 `shutdown` 标记控制工作线程退出。

## 文件说明

- `pc.c`：生产者消费者和任务队列示例代码。
- `pc.md`：条件变量学习记录。
- `pc补充.md`：线程池雏形学习记录。

## 构建示例

```bash
gcc -o pc pc.c -lpthread
./pc
```

生成的 `pc`、`main` 属于编译产物，不建议提交。
